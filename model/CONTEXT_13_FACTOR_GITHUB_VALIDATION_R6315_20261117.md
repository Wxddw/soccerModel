# Shadow R6.3.15 — 13类比赛环境因素：GitHub项目评估和历史样本外对照

研究日期：2026-11-17；生产模型 M79.3.6 继续冻结，R6.3.14原代码完全保留。**本次不授予任何新增概率权重或正式单挑方向。**

## 决策结论

1. **保留** `socceraction`、`soccer_xg`、`kloppy`、`unravelsports`、`statsbombpy`、`soccerdata` 的标准化接口研究价值；尚未验证它们在2025—2026赛前预测中对 M79 的增量优势，不接入正式推断路径。
2. `football-load-injury` 对球员GPS/心率负荷与伤情的研究可参考，但不能迁移其伤病AUC为胜平负指标；项目使用GPL-3许可，要审查兼容性。`Fixture-IQ` 是完整联赛+杯赛+欧战负荷数据管道的较好参考；当前的“仅联赛”简化体能测试**不可以**证明赛程负荷无用。
3. `football-injurylens` README明言仓库内默认CSV是**合成示例**，不能当真实验证。`refstats` README只是Next.js初始化说明，不能证明具备足够的裁判评分模型。
4. 本次仅**真实验证四项历史已知赛前特征**：近期状态、联赛内休息天数、联赛内赛程密度、主客场表现差异。其余因素不能因在 GitHub 找到包而被冒称已经验证。
5. 使用完整比分联合概率矩阵 `Q` 的规定继续适用：未来任何通过验证的特征调整需重新生成统一矩阵，再聚合胜平负、S4、GS、RC、HTFT，禁止五个输出层分头改概率。

| 9. 门将发挥与定位球 | StatsBomb射门、定位球、PSxG等；赛前近年历史数据 | 未取得跨赛季冻结特征，**未验证** | 门将确定缺阵走AIC，实际扑救不准回填 |

| 11. 主客场与球迷氛围 | 主客场已发生赛果；实际观众和氛围资料缺 | 主客场表现代理 **2025训练/2026留出** | 提示值得研究，但跨联赛不稳定，**不晋级** |
| 12. 天气与场地 | 历史气象再分析/赛前预报、球场地面实况 | 无同截点天气历史，**未验证** | 需以赛前已发布预报为准，禁止使用赛时观测冒充预报 |
| 13. 偶然性 | 离散概率分布/情景尾部，无可观察的固定赛前事件 | 不能作为确定性因素拟合 | 使用预测区间、RNG重采样和尾部风险；禁赛后编造“运气因子” |

## 历史验证口径

数据：openfootball/football.json 的英超、德甲、西甲、意甲、法甲 2024-25 / 2025-26 / 2026-27 三季共15个赛果JSON文件，3,733条已记载结果。2024年的比赛只用于滚动预热；2025-01-01至2025-12-31开发1716场，2026-01-01至2026-09-20留出1199场。

注意：用户需求终点为2026-11-16，**此仓库下载版本的2026-27赛季只覆盖至2026-09-20**。故不是至11月16日的全部比赛。数据源最新赛季声明自动生成JSON，但上游原始赛果可能滞后，不能据此宣称当前完整。

模型：独立的近期进失球平滑泊松比分网格，用2025年的赛前标签调整一个log强度差；只在2025开发期网格选择系数，在2026保留期固定不改。逐日期批处理，确保比赛日的结果不会输入同日其他场比赛。统计胜平负Log Loss/Brier、Top1和精确比分Log Loss。**这不是M79正式预测，也不是R6.3.14经过冻结的市场模型。**

| 研究模型 | WDL LogLoss↓ | Brier↓ | Top1命中 |
|---|---:|---:|---:|
| 纯近况进失球泊松基线 | 1.043773 | 0.626813 | 562/1199 (46.9%) |
| +近5场积分差 | 1.043239 | 0.626395 | 558/1199 |
| +联赛内休息天数差 | 1.043284 | 0.626423 | 568/1199 |
| +联赛内14天场次差 | 1.043773 | 0.626813 | 562/1199 |
| +主客场进失球表现差 | 1.039367 | 0.623556 | 573/1199 |
| +四特征联合 | 1.038186 | 0.622588 | 570/1199 |

主客场差异带来的平均WDL LogLoss改善约0.004406，IID逐场bootstrap 95%区间[-0.000716,0.009586]，**跨0**；五联赛分组改善依次：英超-0.004121、德甲+0.007916、西甲+0.017945、意甲+0.003423、法甲-0.006031。综合特征改进0.005587，IID区间约[+0.000002,+0.011314]，但接近0且因比赛相关性、数据源未更新、多个候选比较，**不足以认证正式升级**。这些区间不是联赛聚类或时间区块Bootstrap。

**禁止数据泄露**：实际伤停、中途红牌、赛后天气、门将扑救数据、最终首发名单（若赛前截止时间未公开）均不得进入该截点预测。多次转载同一条伤停新闻只算一个证据家族。

## 新增代码与状态

- `context_evidence_r6315.py`: 11类赛前准入特征 + 4类赛中/赛后禁止变量；时区校验、截止时间检查、来源独立性、不可用信息封锁；仅生成说明性审核结果，**不给出权重或结果变化**。

- `test_context_evidence_r6315.py` 与 `test_historical_context_r6315.py`：新增43个测试，回归410/410通过。

### 晋级标准

只有同时满足以下条件，才考虑将候选升级到Shadow概率挑战层：① 联赛、时间和球队ID可对齐；② 关键特征在实际冻结截点已可观测；③ 赛前-赛果分隔不可逆；④ 至少一段完全独立未来样本上同时改善WDL LogLoss和Brier、不使让球和总球损失明显恶化；⑤ 各联赛表现稳健、置信区间不包含重大退化；⑥ 不将同源数据重复计入市场/阵容；⑦ Score/Grid HARDLOCK和研发正式权责维持不变。

**决定：目前全部候选留在只读Shadow研究层；M79.3.6 Production与Shadow R6.3.14原计算权重/选择权限均不变。**
