## 新增研究层

`selection_risk_r636_20261124.py` 接在 `market_trap_integration_r636.prematch_audit_with_market` 之后。`review_with_original_q` 必须以原联合Q聚合胜平负、官方整数让球、总球八分桶；公布的比分Top3和总球Top3必须与原始Q排序匹配，普通单挑与复选第一项一致。无官方竞彩整数线拒绝运行。旧的两点多公司赔率路径引擎仍原样保留，静态信号不是升退盘证明。

1. **静态跨市场比较**：采用归一化去水概率，要求来源、时区感知真实观察时间、截点前数据，同场两市场观测间隔≤60分钟。竞彩热门概率较欧赔高≥7个百分点提示差异，若竞彩热门≥48%、亚洲让步≤0.5球同时满足差异阈值，提示中度热门浅盘。若客侧热门≥48%、竞彩较欧赔高≥5个百分点且主胜和平局差≤3个百分点，提示客胜保护脆弱。平局买量-竞彩平局市场概率≥8个百分点提示平局热度。买量、欧亚赔均是一个市场证据族，不能证明庄家意图或实际成交。静态观测与真正多公司时间序列分别输出。无普通开售不推导可售普通选择。
2. **Outcome复选**：原始Q第二与第三名差≤3个百分点提示保护二审。仅当市场静态信号相应支持、原Top2排序匹配且目标方向得到两类独立非市场证据（不同源最大匹配计数），才生成 *独立Shadow备选复选*，不改原单挑；客胜保平改防主胜的条件同样严格。普通候选不自动反转。
3. **S4精确净胜差**：原Q聚合官方让球；深盘 abs(JC)>=2 且Top2接近5个百分点或原比分前三有精确让平路径时提示复审；让平落在第三且与第二差≤3个百分点、两类独立非市场目标证据同时满足，才产生替代影子复选，不把让平强塞进单挑。
4. **RC总球候选**：报告原Q高/低尾质量及最优被排除具体整数桶与第三槽差值。差≤2.5个百分点、原排序正确、两类独立目标证据且另一端无双信号冲突，才生成单一替代槽的影子Top3，保护原Top2。7+是竞彩累计桶，不是精确7球。此替代只是选择规则实验，不伪称为原Q概率排序；若以后重新拟合Q，仍须全套跨层重算。
5. **GS与HTFT**：拒绝混用旧比分与新总球概率；HTFT完整九分类与全场Q边缘一致且第二第三差≤3个百分点只触发审查。缺九分类不校准。11月23日没有可验证完整矩阵，因此不回填任何参数。六时段双球差研究沿用11月23日候选。
