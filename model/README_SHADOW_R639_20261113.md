# M79.3.6 Production（完全冻结）＋ Shadow R6.3.9（2026-11-13）

**依据：** 2026-11-12（周四）6场欧国联的上轮对话所发布赛前参考与赛果复盘。**证据边界：** 对话发布的6场方案没有完整、同截点、可核查的正式赛前冻结矩阵，**因此本包不是正式M79.3.6回测、不是独立验证，也没有证明升级后命中率提高。**

## 版本变化

正式版 M79.3.6 Production 不变；R6.3.3～R6.3.8 的所有代码、文件与历史输出不改。R6.3.9继承`shadow_r638.inspect()`，新增4个**只读研究诊断模块**，不会修改概率、冻结单挑、冻结保护、冻结让球、比分Top3或任何正式授权。新增研究阈值**未拟合、未独立验证**，不得直接并入正式版。

### P0 — S4 v1.9：竞彩整数盘口“净胜差 × 比分”跨层审计

- 仅接受赛前时间戳的**实际竞彩足球整数让球线**及**同截点且通过WDL/总球一致性检查的联合比分矩阵**。盘口正数表示主队受让，负数表示主队让球。
- 重新列示让胜、让平、让负三个聚合概率，并检查 **让平=净胜差 `主队进球−客队进球=−竞彩盘口`**。
- 输出比分Top3各自的让球归属、此前冻结让球主选、聚合方向Top1及第二方向、让平与Top1的差值。
- **触发研究人工复核：** 冻结让球主选与聚合Top1不同、比分Top1落点与冻结让球主选不同、比分Top1落点与聚合Top1不同、两个Top3比分同属让平而旧让球主选不是让平、或者聚合Top1并非让平且让平相差不超过5pp。
- **数学澄清：** 单一最高概率比分对应让平、但所有比分聚合后让胜概率更高，可以同时成立。这是模型层级不一致的观察提示，**不能判为计算错误、不能强迫让平成为Top1**。
- 比分Top3顺序、旧冻结让球主选均不动。`formal_handicap_grant`始终是`null`。

### P1 — Protection v0.3：三方向拥挤与被排除的平局

- 原单挑方向为原WDL概率Top1；保护候选仍为Top1+第二名，**禁止直接插入平局或调概率**。
- 研究人工复核触发条件之一：最大/最小概率差≤5个百分点（典型如本轮002研究概率：主胜33%、平31.3%、客胜35.7%）。
- 第二条件：研究保护对排除平局、且平局与第二名概率相差≤3个百分点（002的平局落后第二名1.7pp）。
- 继承原R6.3.6的第二/第三名差≤1pp保护封锁；新增门只阻止释放**研究候选**，不发放/撤销正式投注授权，也不更换原独立冻结记录。
- Top1<40%只出研究方向，标记低置信，不授正式单挑。所有临界百分点是**未拟合的研究提醒**，不是概率改动。

### P2 — ESR v0.2：回归、补招、预计首发、确认首发不能混为一谈

新增可选字段 `squad_movements`，每条需要 `kind`（`squad_return`/`new_callup`/`projected_starter`/`confirmed_starter`/`confirmed_unavailable`）、`side`、`player_id`、`source_id`、`observed_at`。

- `confirmed_starter` 要求在冻结截点之前存在同队正式11人名单，且该球员确实在内；`projected_starter` 同理必须匹配预计首发。
- `confirmed_unavailable` 不能与同截点正式首发矛盾；所有信息晚于冻结截点时拒绝运行。
- `squad_return`和`new_callup`不表示必首发，也不能单凭补招/回归推断队伍进球能力或立即赋予正向评级。有效贡献必须通过单独ESR球员质量和预计分钟输入完成。
- 阵容+伤停+补招/轮换全部仍归一个roster证据家族，**不能重复投票**。

### P3 — GS1.6：比分集中度与分层审查

在原联合矩阵上只计算比分Top1概率、Top3概率和、Top3以外质量、比分Top3对应的胜平负/总进球桶分布及比分众数与Outcome Top1是否相同；不改Score Top3。两者众数不同可以是合法概率现象，并非自动反转或报错。
