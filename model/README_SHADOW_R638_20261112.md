## 新增模块

### LCRG v0.1：正式首发大轮换与预计首发偏差
新可选输入 `lineup_snapshots.home` / `lineup_snapshots.away`，每队最多三种来源，均须有 `source_id`、`observed_at`、11个不重复的 `player_ids`、正确`basis`：

- `reference`（basis=`last_league_xi`）：最近联赛首发基准，仅用作实际轮换参照，并不等于球队最强阵容。
- `projected`（basis=`precutoff_projected_xi`）：赛前预计首发。
- `official`（basis=`official_starting_xi`）：正式公布首发。

所有时间不晚于当前冻结截点；reference/projected不能晚于official。必须用新冻结截点重跑，禁止把开赛后或原截点之后的新首发补录到旧版输出。

- 与最近联赛首发基准相比，变更**6人及以上**：`HOLD_CORE_LARGE_REFERENCE_ROTATION_NEEDS_ROLE_QUALITY_REVIEW`，仅暂停研究核心审查，需ESR判断替补质量。
- 预计与正式首发相比，变更**4人及以上**：`HOLD_CORE_LARGE_PROJECTED_LINEUP_SURPRISE`。
- 实际轮换≥3人或首发偏差≥2人：`WATCH_MATERIAL_LINEUP_CHANGE`。
- 其余输出观察。无证据输出UNKNOWN，不臆测安全；只有11人姓名变化不能证明实力下降，更不能自动反转单挑方向。

上述3/6、2/4阈值是**预先声明的研究守门启发式参数**，不是本轮6场拟合或取得准确率认证的阈值。阵容、伤停、轮换只计一个`roster`独立风险家族，不得拆成多个独立票数；赛程、战意仍按照原MSI/DVRG去重。

### S4 v1.8：让平 = 竞彩整数盘口对应的精确净胜差
- 只有在官方竞彩整数让球线及其赛前时间戳、**同一可校验联合比分矩阵**存在时计算。
- 若主队让-1，则`让平 = 主队净胜1球`；若主队受让+1，则`让平 = 客队净胜1球`；通用目标 `主队进球−客队进球 = −竞彩让球线`。
- 输出让平概率、在让胜/让平/让负中的排名、与最大概率的差值及对应比分族。让平排名前2时增加*观察提示*，**不强制挑让平、不改让球Top1和原冻结选项**。
- 亚盘-0.5、-1.5不能替代官方竞彩整数让球线。

### RC2.6：0、1、7+完整性观察
- 审计 `P(0)`、`P(1)`、`P(7+)`、`P(2)+P(3)`，不拟合任何总球概率或“高尾乘数”。
- 精确Top3观察只能从`0..6`整数桶产生；`7+`是聚合概率桶，不等于单独的`7球`概率，也不等于一项具体的总进球数。
