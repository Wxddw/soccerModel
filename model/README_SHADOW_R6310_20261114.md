# M79.3.6 Production冻结 + Shadow R6.3.10（2026-11-14）

## 0. 版本和证据边界

- Production：**M79.3.6，仍然完全冻结**。无法由本研究包恢复完整正式生产权重或声称完成生产部署。
- Shadow基线：R6.3.9，继承其代码及全部历史记录，不修改旧文件。
- 新增R6.3.10：**只读诊断层**，不校准参数、不训练、不改Outcome三项概率、不自动反选、不修改原比分Top3/Goal Top3、不授予正式单挑/核心/复选/让球。
- 输入需先通过继承的**赛前截点校验**。研究版对正式竞彩**整数**让球盘口与冻结选择保持数据契约。亚洲让球不可代替。
- 依据的是11月13日001—011的**历史对话赛前参考与随后复盘**，而不是从原始生产执行日志恢复的同截点赛前矩阵；只用于开发审计，**不允许作为训练、拟合、独立留出验证**。

## 1. P0：S4 v2.0 竞彩整数净胜差边界

在原R6.3.9 `S4_v1_9_margin_score_decision_review`基础上，对来自同一联合比分矩阵的全部比分计算有符号净胜差 `主队进球−客队进球`，分开输出概率与该边界两侧±1球的概率、Top3示例比分。

- 官方整数盘口为`L`时：让平 **净胜差 = −L**，让胜 **净胜差 > −L**，让负 **净胜差 < −L**。
- `−1`、`−2`、`−3`、`+1`、`+2`、`+3`均按相同映射处理，不将“客胜”混作“穿盘”。
- 逐场输出让胜/让平/让负完整聚合概率、原冻结让球选项、第一/第二差距与边界两侧概率。
- 继续沿用“前二概率差≤5个百分点”以及“让平距离Top1≤5个百分点”**只读人工复核**，不自动选让平、不全局放大净胜1/2/3球概率。
- 比分Top1落在让平但让球聚合第一是让胜/让负时，属于**合法不同层面的概率众数**，不是数学错误；只有内部聚合概率不一致才拒绝。

## 2. P1：GS1.7 比分家族覆盖

基于验证通过的联合比分矩阵，保留原精确比分Top3不变，额外计算：

- 精确比分Top3概率质量；胜/平/负三个结果家族各自概率、Top3贡献的家族质量、家族覆盖率及遗漏质量；
- 双方进球、0:0、主队0球/客队0球概率；
- 矩阵中精确5球与7+总球聚合概率。

这使研究者能分辨 **Outcome正确而精确比分候选覆盖不足** 的情形，但不会用事后比分“补进”Top3。

## 3. P2：RC2.7 总进球双尾与4/5球

对赛前`goal_distribution`的0、1、2、3、4、5、6、7+各桶进行原样检查，新增0/1、2/3、4+、5+结构的只读聚合。7+只是**聚合概率桶**，不可标成某一个精确进球数。不重新排序精确Goal Top3，不给0球/7+强制插槽，不用这一轮7:0进行反向拟合。

## 4. P3：Selection Context v0.8 风险门

新增可选 `competition_context`，必须含来源和赛前时间戳：

```json
{
  "competition_context": {
    "source_id": "official-competition-document",
    "observed_at": "2026-11-14T18:00:00+08:00",
    "competition_kind": "competitive",
    "selected_side_objective": "draw_sufficient",
    "allowed_substitutions": 5
  }
}
```

- `competition_kind`只接受`competitive`或`friendly`；`selected_side_objective`只接受`unknown`、`win_required`、`draw_sufficient`、`no_objective_identified`。
- 有明确赛前来源证明“已选方向球队保平即可完成目标”时，仅触发核心人工审查，不把战略目标自动转成平局概率；友谊赛及已确认允许多次换人，也只触发轮换审查。
- 情报未知就标记未知，不当作安全；新增审查不增加“独立风险家族票数”，避免与MSI、ESR、赛程或伤停重复计算。
- 本研究版不会放宽已有的`Top1<40%`规避、WFC、NCG、超低赔二审及全部正式授权规则。

目前本包回归测试**185/185通过，0失败（继承旧150 + 新35）**。这些是**代码契约回归测试，不是185场比赛验证，也不意味着模型准确率提高**。

申请正式晋级前必须完成至少50场、建议100+场**新日期、独立比赛**的赛前冻结双轨对照，比赛和盘口、证据时间戳一致，先验证：

1. 单挑命中率与覆盖率、保护命中率、避免误封正确方向；
2. 官方整数让球整体正确率、让平精确边界召回、非让平误报；
3. Goal 0/1/4/5/6/7+多分类校准（完整Brier / Log Loss）、中央峰值覆盖、Goal Top3；
4. 比分Top3质量、比分家族覆盖率及Score/Goal/Outcome/JChandicap的联合一致性；
5. 分组对照友谊赛、保平达标、关键人员缺阵、主/客强热门。

研究门本身若只提供警告、不改概率/选择，则不应声称Brier/Log Loss或命中率改善。若只是通过更高比例规避来“提升胜率”，需要同时报告覆盖率及机会成本。不能把开发集后验优化冒充独立认证；正式版仍冻结。
