# R6.3.6｜2026-11-21 赛后问题修复：赛前跨层发布审查（Shadow）

**正式版 M79.3.6 Production 完全冻结，不修改概率、赔率、正式单挑和权限。**

## 为什么修改

11月20日竞彩001—008赛前文本选择（11月21日复盘）暴露出主胜方向与半全场主队最终获胜路径的集中度过高，且比分Top3与整数球分布跨层审查不足。**该批次只有公开聊天选择与赛后比分，并无相应完整冻结的Production Q(H,A)，禁止把它当作新模型的真实前向验证。**

## 新增代码与功能

- `matchday_publish_gate_r636.py`：研究层审查；输入一场完整归一化的赛前联合比分矩阵 Q、独立源时间戳、竞彩官方带符号整数让球线、原始单挑和候选；所有胜平负、净胜差、让球、0—6/7+总球从**唯一Q**聚合。原比分Top3与总球Top3如果与Q排序不符，分别封锁对应输出；不改写原概率。监测净胜1/2球、0/1低尾、4球边缘、5/6/7+高尾以及中央2/3候选。
- 半全场：若提供九分类概率，必须和Q的全场胜平负边缘精确相等，主选/备选需依九分类真实排序；缺少九分类概率时，不授予经过概率验证的半全场。检测多场`平胜`或`胜胜`方向高度集中的问题，但不因此机械提高`平负`/`平平`。
- Outcome：发现原单挑与Q众数冲突时只触发二审。赔率/成交量等重复市场信号不单独授予反转；反转至少需要**两个不同非市场证据族、两份不同来源、登记于截点之前的方向差阈值**，且只是**人工审查资格**，绝不自动改变原预测。源独立性仍需人工审计。
- AIC：验证关键球员位置GK/CB/FB/DM/CM/AM/W/ST、预期分钟、替代者角色、伤停获取时间；替补不确定或位置错配仅报告风险，禁止生成虚构xG增减。**比赛中发生的新伤或真实换人分钟禁止作为赛前输入**。
- 集中度：批量检查可售单挑主胜占比、半全场主选“最终主胜”的占比。仅为发布风险报告，不属于任何模型胜率提升的证据。

## 冻结与晋级门槛

1. 四级修复优先级仍为：联合比分—净胜差 → RC整数总球双尾 → AIC替代/时间状态 → Outcome热门反转。半全场六时段保留平行研究Shadow，已有9场回顾性敏感性对照显示未稳定改善，**不得因昨天1/8而直接提高平负**。
2. 各模型需要**同一赛前冻结时间点**的完整 Q、官方线、阵容信息、时间戳；曾经缺失Q的旧聊天预测不能事后重建后称为前向样本。
3. 在新的时间顺序留出样本上同时比较九分类和整数进球的 Log Loss、Brier、Top1/Top3；Outcome还要审计原方向正确被错误反转的损失。无独立样本前不改Production或正式`核心/观察/规避`授权。
4. GitHub工作分支 `research/r636-matchday-audit-20261121` 从之前的 `research/r6.3.6-postmatch-repair-20261119` 建立；未修改`main`或M79正式文件。可通过不合并该分支完整回滚。
