## 新增模型模块（全部研究候选，不改旧模型权重）

### 1. 条件联合比分校准候选 `joint_tail_calibration_shadow_r636.py`

在**同一个完整赛前 Q(H,A)** 上，按 `E[总球]` 事先分为低、中、高三个预期节奏类别（初始研究固定阈值 `<2.6`、`2.6...<3.7`、`≥3.7`；没有真实样本外确认）。每类用更早已完赛且提供赛前冻结 Q 的历史样本估计 **6个**正则化加权特征：

1. 总球≥4；2. 总球≥5；3. 净胜差绝对值≥3；4. 双方都至少进2球；5. 总球0/1；6. 精确3球。

新参数仅在**同一全场胜平负类别内**对原比分单元施加条件指数倾斜并按该类别归一化，严格保证普通全场胜平负三项边缘不变。**进球数/比分/净胜差/竞彩整数让球是新的整体候选**，必须用新 Q 重新派生，并分别记分，不能只改比分Top3而继续使用旧 Goal 或 JC。

默认要求 ≥80 真实更早且授权分析的历史比赛，并且对应预期节奏子类 ≥35场才能出该类校准；无法达标则**拒绝预测而不是套用新权重**。这些是程序安全下限，不等于拥有统计认证。未训练或新比赛被用于训练等均直接封锁。

### 2. 真正配对回测 `benchmark_joint_tail_shadow_r636.py`

只能用独立且原始保存的**历史开球前完整 Q** 训练（及其赛后真实结果），并要求**训练的赛果出现时间早于留出集最早赛前观察时间**。在相同留出样本、相同官方竞彩整数盘口下比较：

- Score：Top1/Top3、精确比分Log Loss、Brier；
- Goal：Top1/Top3、精确整数双选、0..6/7+桶Log Loss、Brier；
- JC：让球三分类Top1、Log Loss、Brier；
- Outcome：全部三项严格沿用原 Q（不允许方向反转）；
- 配对Bootstrap置信区间，分预期节奏报告覆盖。

不允许仅因Top3命中率提高就宣布升级；如Score提高而Goal/JC Log Loss或Brier恶化，按跨层红线保持Shadow。

### 3. 六时段双球差新模型 `htft_margin2_timeseg_shadow_r636.py`

前六时段研究仅区分领先/落后，本次单独加入“领先1球、领先≥2球、落后1球、落后≥2球”，对主客队形成8个可从更早真实进球事件拟合的条件强度系数。阶段：00–15、16–30、31–45+、46–60、61–75、76–90+。**阶段边界**调整进球强度，不会伪称可预测分钟内发生换人、红牌或某次进球。

模型对每一个原始FT比分单元重新归一化阶段路径，使原全场Q、普通胜平负、进球数和竞彩让球边缘**严格保持不变**。同时输出：

- 九分类半全场Top1/Top2/Top3;
- 中场分差：领先2+、领先1、平、落后1、落后2+;
- 半场领先2球最终未赢/半场落后2球最终获胜的赛前情景概率;
- 每个15分钟区间的主客期望进球。

须有 **≥80** 场更早的带精确进球分钟、半场全场比分、真正赛前xG、时区感知的观测/赛果时间戳的合格历史比赛才可拟合，且仅输出Shadow。此处尚没有完成真实匹配训练，不能声称六时段预测提高。

### 4. 半全场九分类风险审查 `htft_regime_watch_r636.py`

按同一全场 Q 严格检验九分类FT边缘一致性，统计“胜负/负胜/负平/胜平/平平/平负”在全场配对Top2内的覆盖和总概率质量。支持显式声明源数据**五位小数舍入容差**，不悄悄归一化缺失概率；没有九个类别则失败。主备Top2不低于预期也不意味着主选Top1已校准。

## 数据隔离/禁止动作

- 所有历史训练行：`观察 <= 截点 < 开赛 < 赛果记录 < 训练截点`，训练截点必须早于未来预测的赛前观察；同场ID不得同时出现在训练和预测中；训练数据需自述有分析权利且实际来源须独立检查。
- 2026-11-22复盘的巴萨0-2→3-2、马赛2-0→2-3、亚特兰大4-4只是**开发诊断案例**，未用来拟合参数或试图提升这16场命中率。
- 所有训练系数有缩减和上限，限制过拟合的影响，但不是证明预测准确率提高。
- 不能把“半场已知道0-2”的现场预测提升冒充赛前提升。
- 新Q的HTFT必须由新Q重新计算。**不得使用旧Q对应的九分类搭配新Q**。
- 对未获取到确切伤停、预计上场分钟、历史赛事授权和来源时间戳的场次，不得编造赛前特征。
- 不对正式Production权重、单挑、保护、分级或历史预测做任何改写。
