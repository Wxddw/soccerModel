## 3. HFRG v0.1：主场热门风险门

适用对象：原始WDL Top1为主胜，且主胜概率不低于50%的主场热门。

风险证据家族按底层原因去重：

- roster：伤停、正式首发、门将、后防中轴、替补质量，全部归同一阵容家族；
- schedule：密集赛程、短间隔、轮换，归同一赛程家族；
- tactical：对手反击/压迫/定位球对位、换帅首战等，归同一战术家族；
- market：欧赔、凯利、交易价格/成交量等归同一市场家族。

触发规则（预先声明的研究门槛，不是拟合出的概率系数）：

1. 一项严重关键位置损失（门将或中卫/后腰中轴的有效阵容质量显著下降）→ `HIGH_RISK_REVIEW_CRITICAL_SPINE`；
2. 两个独立证据家族同时对主队不利 → `HIGH_RISK_REVIEW_TWO_INDEPENDENT_FAMILIES`；
3. 只有一个不利家族 → `WATCH_ONE_ADVERSE_FAMILY`；
4. 少于两个独立风险家族 → `UNKNOWN_INSUFFICIENT_INDEPENDENT_RISK_AUDIT`，未知不等于安全；
5. 至少两个家族且没有不利信号 → `NO_HFRG_TRIGGER_REVIEWED`。

HFRG只能暂停核心审查/要求二审，不能自动反转主胜、改变WDL概率或改写正式保护。

## 4. 动态保护复核

研究保护按同一份WDL概率执行：**唯一Top1 + 其余两个结果中概率更高者**。

- 不再默认主胜就配“胜平”；例如复盘输入周四007为39%/28%/33%，研究保护应为“胜负”，而不是“胜平”。
- 若第二、第三候选概率差不超过1个百分点，视为整数概率/四舍五入造成的排序不确定；保留此前合法保护对并标记人工复核，不擅自制造精度。
- 冻结保护字段保持不变；新保护只作为Shadow建议。

### 13场对话复盘的描述性重算

- 原保护：8/13；

这只是上一轮对话数据的算术重算，不是独立验证，也不代表长期保护命中率提高。

## 6. RC2.4：整数总进球尾部路由

总进球分桶统一为 `0/1/2/3/4/5/6/7+`。中央峰值必须保留；只有至少两个独立赛前证据家族同向时，才允许Shadow候选占用一个尾部槽：

- 高尾：4/5/6/7+；
- 低尾：0/1；
- 高低尾两侧同时触发：冲突时保留基础Top3，不强行换槽；
- 最多一个尾部槽，不因单场4球或7球赛果整体抬高高尾概率。

概率不被修改；Shadow只输出候选Top3及证据家族。

## 7. GS1.3：比分联合矩阵审计

如果输入完整比分联合矩阵：

- 由同一矩阵聚合胜/平/负；
- 由同一矩阵聚合0/1/2/3/4/5/6/7+总球分布；
- 检查比分Top3；
- 输出0—1低事件、2—3中央、4+高事件，以及净胜1球/净胜2+球/平局等比分家族覆盖。

比分矩阵WDL边缘分布与Outcome概率、总球边缘分布与Goal概率的最大差异均要求不超过1.5个百分点，否则直接报错，不允许分别独立拼出互相矛盾的胜平负、总球和比分。

没有完整矩阵就返回UNKNOWN，不从Top3比分反推伪概率。
